## 一、功能总览

- **可视化编辑**：拖拽/缩放/平移 对象、无限画布（到边自动增长），所见即所得。
- **两种环境**：
  - `tikzpicture`（picture）：文本、各类形状、箭头、函数、坐标轴、网格，功能全。
  - `tikzcd`（cd）：`\begin{tikzcd}` 矩阵视图，网格化"单元格"，只做文字 + 箭头。
- **tikzcd 多图并列**：一个代码块里写多个 `\begin{tikzcd}` 环境（用 `\quad \quad` 等
  分隔，可各自带 `[row sep=…]` 选项）→ 编辑器把所有图同时显示在同一个网格里
  （后图整体右移一个空列），全部可编辑；写回/插入时按图拆分还原环境与分隔符。
- **Vim 风格**：NORMAL / INSERT / ARROW EDITING 三种模式，键盘全程可操作，无鼠标也行。
- **所有键可配置**：Settings → Keybindings，按命令逐项重绑（单键 / 多键序列 / `mod+X`）。
- **快捷键速查表**：按 `?`（或工具栏 **? Keys**）随时调出——表内容直接读当前键位配置，
  改过键位也不会过期。
- **实时预览**：画布即渲染——对象直接按模型绘制在 SVG 上（数学经 KaTeX 排版），无内核、无网络依赖；
  Code 标签 `Ctrl+E → Ctrl+S` 可手写代码并即时应用回画布。
- **属性面板**：Graph / Axis / Grid / Functions / Arrows / Reference / Nodes 七个区块（picture 模式）。
- **代码编辑**：CodeMirror 6 代码标签页，只读预览 ↔ 编辑（Ctrl+E）→ 应用（Ctrl+S）。
- **一键插入当前笔记**：`ok` 把生成的代码块写回当前打开的 `.md`。

## 二、安装

把仓库里构建好的三个文件拷贝到 Obsidian 库的插件目录：

```
<你的库>/.obsidian/plugins/tikz-editor/
    ├── main.js
    ├── manifest.json
    └── styles.css
```

然后在 Obsidian：**设置 → 社区插件 → 已安装插件**，启用 **TikZ Editor**。
（若插件菜单里没有，直接是社区插件目录不存在：先创建目录再放文件，或重载 Obsidian。）

## 三、首次使用

- 无需任何下载，打开即用（预览为编辑器自绘 + KaTeX 数学排版，完全离线）。
- **解析保护**：若笔记里的代码块无法解析，会弹出提示并打开空白画布；此时原块受保护，
  Insert 不会覆盖它（先在 Code 页 `Ctrl+E` 编辑 → `Ctrl+S` 应用后再插入）。
- **Esc 自动写回**：按 Esc（或点击遮罩）关闭编辑器时，若有未写回的修改，生成的代码会
  **自动写回笔记**——编辑已有块时原地替换，新建模式在光标处插入；成功后草稿清除。
  无法安全写回时（无活动笔记 / 已切到其他笔记 / 原块位置变化 / 原块解析失败）不会硬写，
  自动存为草稿，下次打开同一代码块提示恢复。无修改则什么都不写。

## 四、打开编辑器

- **命令面板**：`Open TikZ Editor`（`Ctrl/Cmd+P` → 搜“TikZ”）。
- **左侧 Ribbon 图标**（git 分支图标）。
- 建议在 **设置 → 快捷键** 里给它绑一个自己的快捷键（插件本身不预设）。
- 行为：
  - 光标悬停在某个 ` ```tikz ` 代码块内 → 加载该代码块进入编辑；
  - 否则 → 新建一个默认模板图（默认环境为 `tikzpicture`，可在设置里改成 `tikzcd`）。
- 编辑完成后用 `ok`（或工具栏 **Insert**）把代码写回笔记并关闭编辑；**Esc 关闭时会自动把
  未写回的修改写进笔记**（无法安全写回时存草稿，见 §三），无需记得先按 Insert。

## 五、界面布局

**tikzpicture 模式（picture）**：

```
┌─────────────────────────────┬──────────────────────────────┐
│  工具栏 Toolbar（创建/撤销/Fit/代码/速查表/插入/cd 工具）    │
├─────────────────────────────┼──────────────────────────────┤
│  属性面板 Properties (≈40%)  │  预览/编辑画布 (≈60%)        │
│  Grid / Axis / Grid /       │  （对象即所见，无限画布）     │
│  Text / Shape / Arrow /     │                              │
│  Graph / Reference          │                              │
├─────────────────────────────┴──────────────────────────────┤
│  状态栏 [NORMAL MODE] <键位提示> <命令缓冲> <状态消息>       │
└────────────────────────────────────────────────────────────┘
```

- **工具栏**：Text、Shape（矩形/圆形…）、Arrow、Undo/Redo、**Fit**（缩放至适应窗口）、**Open Code**、**Copy Code**、**? Keys**（快捷键速查表）、**Insert**；
  cd 模式下还多出 **Arrow tool** / **Pan tool** 切换（可以固定箭头/平移工具，不必一直按 Shift/Space）。
- **属性面板顶部导航**（左属性栏）：Graph / Axis / Grid / Functions / Arrows / Reference / Nodes
  七个区块可点击跳转；标签上方另有 **Properties / Code** 两页签切换。`mod+f` 直接聚焦节点搜索。
- **Code 标签**见 §十四。

**tikzcd 模式（cd）**：整屏换成参考编辑器（Preact）：

```
┌──────────────────────────┬──────────────────────────────┐
│ 舞台 stage (60%)         │ 代码面板 code (40%)            │
│  网格 + 单元格 + 工具箱    │  顶部: Insert / Back to editor │
│  (Pan/Undo/Redo/…)       │  textarea（实时 tikz 代码）     │
│  属性面板(选中箭头时)       │  底部: Parse 解析             │
├──────────────────────────┴──────────────────────────────┤
│  状态栏 [NORMAL MODE] [cd 键位提示]                        │
└──────────────────────────────────────────────────────────┘
```

> 提示：cd 模式下没有库内熟悉的属性面板，箭头/格子样式用快捷键直接改（见 §11/12），完整 UI 是右侧代码。

## 六、两种环境：tikzpicture 与 tikzcd

- **切换**：在 NORMAL 模式输入 `env`（命令 `normal.toggleEnv`，默认只对 picture 生效）。
  从 cd 返回 picture 用 cd 代码面板标题栏的 **Back to editor**（行列朝向保持不变：
  cd 网格第 0 行是顶行，回到 picture 画布后仍在上面）。
- `tikzpicture` → 自由画布，可缩放/平移，支持 文本/图形/箭头/函数/轴/网格。
- `tikzcd` → 矩阵网格视图：
  - 单元格吸附 1.6cm 网格；
  - 只做两件事：**格子文字 + 格子间箭头**；
  - 生成 `\begin{tikzcd} … \end{tikzcd}` 环境与 `\arrow[...]` 行。

通用（picture + cd，cd 的画布即网格）：

| 操作 | 效果 |

| 左键拖空白 | 平移画布（或按住 **Space** 临时平移） |

## 九、INSERT 模式（文字编辑）

- 编辑对象的文本，支持 `$...$` 数学公式（KaTeX 渲染）与多行（`Enter` 换行）。
  行间公式 `$$…$$`、`\(…\)`、`\[…\]` 同样正确渲染（不会漏出多余的 `$`）。
- **箭头有两栏文字**（线上面 `text` / 线下面 `textBelow`）：`Tab` 切换两栏；
  切换时**光标停在原处**，不会被拉到行首。
- 新建对象按下 `i` 时，光标会自动落到 `$…$` **中间**，直接敲数学内容即可。
- `Alt` 返回 NORMAL；把 `Esc` 用于关闭窗口（不丢失内容）。

## 十一、tikzcd 网格模式快捷键

进入 cd 模式后，vim 层把键盘完全交给 Preact 参考编辑器（手柄在 `src/cd/App.js`）。

### 无选中格时

| 键 | 功能 |
|----|------|
| `↑↓←→` 或小键盘 `1–9` | 移动单元格光标（九宫格，`y` 向下） |
| `Enter` / `i` | 编辑当前格文字（空白格则先创建） |
| `a` 然后方向键 / 数字键 | **一键建箭**：从当前格向该方向，自动创建+选中 |
| `x` | 锚定当前格为起点 → 方向键移到目标格 → `Enter`（或再 `x`）确认 |
| `dd` | 清空当前格文字（箭头选中时 `dd`/`Delete` 删除箭头；删除后约 0.4s 内多余的 `d` 会被忽略，防止误清格子） |
| `u` / `Ctrl+Z` | 撤销 |
| `r` / `Ctrl+Y` | 重做 |
| `cp` | 复制生成的 tikz 代码到剪贴板（成功有提示） |
| `ok` | 插入代码并退出 |
| `env` | 返回 picture 画布（需无选中箭头，等同代码面板 **Back** 按钮） |
| `Tab` | 循环选中：选中箭头时循环同起点箭头，否则循环格子 |
| `Alt` / `Esc` | 退出覆盖层 / 取消动作 |
| 按住 `Shift` 或 Arrow tool | 从格子拖出箭头 |
| 按住 `Space` 或 Pan tool | 平移画布 |
| 按住格子 ≈0.3s 或拖 grabber | 移动格子（普通点击仍是编辑） |

### 数字方向对照（九宫格）

```
7 8 9
4   6     ←  对应：1=↙ 2=↓ 3=↘ 4=← 6=→
1 2 3        7=↖ 8=↑ 9=↗
```

方向映射定义在 `src/cd/App.js` 的 `dirs` 表。

## 十二、tikzcd 箭头编辑（选中箭头时）

在 cd 网格里单击一个箭头（或刚建完的箭头）→ 舞台侧出现 **Arrow Properties** 面板，每个按钮带徽标键，直接输入该键即可设样式：

| 键 | 功能 |
|----|------|
| `op` | 反转箭头（反向） |
| `t` | 循环尾部：default → 映射 `mapsto` → 钩 `hook` |
| `h` | 循环头部：default → 燕尾 `harpoon` → 双头 `two heads` |
| `l` | 循环标签位置：左侧 / 右侧 / 内侧 |
| `ds` | 虚线 |
| `dt` | 点线 |
| `sd` | 实线 |
| `db` | 双线 |
| `p` | 隐形（phantom，不显示但占位） |
| `↑` / `↓` | 标签平移：左移 / 右移（显示偏移量） |
| `Shift+↑` / `Shift+↓` | 弯曲：左弯 / 右弯（步进式） |
| `e` | 移动箭头终点：方向键移动端点格，`Enter` 固定，`Esc` 取消 |
| `Enter` | 编辑箭头标签文字 |
| `dd` | 删除箭头 |

**自环箭头**（格子上的 `.loop` 按钮创建）：此时 `e` = 旋转角度（每次 90°）。

> 状态栏 `cdØ:` 会实时显示键位提示；属性面板每个按钮的徽标即为对应键位。

## 十三、属性面板（Properties）

仅 picture 模式显示。标签页顶部导航（NAV）：**Graph / Axis / Grid / Functions / Arrows / Reference / Nodes**。

- **Graph**：环境设置、画布默认宽高、图整体参数。
- **Axis / Grid / Functions**：坐标轴、网格的显隐/颜色/间距；函数表达式列表（每行一个，
  支持 `x` 变量与数学函数，用于 `\draw plot (\x,{...})`）。
  - 坐标轴三种样式（Box 四边框线 / Middle 穿过原点 / Axes 仅坐标轴）+ 极坐标，
    画布预览与生成的 LaTeX 完全一致。
  - 每个函数可填 **Name 名称**（会随代码一起保存，不会在导出时丢失）。
  - **Multi-function plot 多函数绘图**：每行一个表达式，一键插入多曲线模板。
- **Arrows**：箭头样式（头/尾、线型、颜色、粗细）。
- **Nodes**：当前选中对象（文本/形状/箭头）的属性：内容、尺寸、颜色、位置。
  - 颜色用选择器挑；自定义颜色会校验，写错会当场提示（不会生成编译不过的代码）。
- **Reference**：只读速查（快捷键 ↔ 对象），部分尚未自动生成。

## 十四、代码标签页（Code）

- 默认**只读**，展示当前模型的生成 `tikz` 代码。
- **Ctrl+E**：进入编辑态（CodeMirror 6）。
- **Ctrl+S**：应用代码 → 重新解析+渲染（生成 model 反同步到画布）。
- 编辑时**不实时渲染**，避免卡顿；Run 后模型跟上。
- 不认识的代码行会原样保留（`rawSnippets`），生成时原样写回。
  → 你可以手写复杂 TikZ，编辑器只改自己认识的部分。
- 支持的写法（解析器都认）：
  - `\node[opts] (name) at (x,y) {…}`、`\node[opts] at (x,y) {…}`、`\node[opts] (x,y) {…}`；
  - 箭头端点可以写 `\draw[->] (tkz_xxx) -- (3,1);`，也可以写**你自己起的节点名**
    （`\draw (…) rectangle (…) node[name=box1]{…};` 再 `\draw[->] (box1) -- (3,1);`），
    甚至写在节点定义之前（转发引用）。
  - 坐标括号里允许有空格：`( tkz_x )`、`( 3 , 1 )` 都能解析。
- **生成器只产出这些**：`\node`、路径矩形/圆、`\draw ... -- ...`、`\draw plot(\x,{...})`、
  网格/坐标轴标注，以及 tikzcd 的 `\arrow[...]`。生成的代码为标准 LaTeX/tikz-cd 文档。
- 函数没有"名字"概念，函数名用一行标记注释承载（不影响编译）：

  ```latex
  % tkz-function: myCurve
  \draw[blue, domain=0:9, samples=150] plot (\x, {(sin(\x))});
  ```

  这行注释会被解析器读回，所以**函数名在导出/导入后不会丢**。

## 十五、设置（Settings）

入口：Obsidian 设置 → 社区插件 → TikZ Editor → 齿轮。

| 项目 | 说明 |
|------|------|
| `defaultEnv` | 新建图默认环境：picture / cd |
| `defaultWidth / Height` | 空画布默认尺寸（cm）（内容延伸会自动撑大） |
| `defaultZoom` | 默认缩放 |
| `defaultTextWidth/Formula/ShapeSize/ArrowLength` | 新对象默认参数 |
| `focusLeft / focusRight` | 面板聚焦快捷键（默认 `mod+h` → **画布**，`mod+l` → **属性面板**） |
| `undoKey / redoKey` | 编辑器内 Ctrl 撤销/重做（picture 画布与 cd 面板共用；`Ctrl+Shift+Z` 永远可用作重做别名） |
| **Keybindings 键位设置** | 全部编辑器键位（按 group 分组渲染，可改可 Reset） |

**键位格式**：单个键（`t`）、命名键（`Enter`、`ArrowUp`、`Space`）、NORMAL 模式下输入的多键
序列（`redo`、`op`、`ok`、`env`）、或 `mod+N` 系统快捷。多键命令按**前缀**匹配，单字符立即生效；命令可写逗号分隔的多个别名（如 `u,mod+z`）。

*每个分组有独立 Reset 按钮，可一键恢复该组默认键；存在重复绑定时设置页顶部会显示 ⚠ 冲突列表。*

## 十六、常见问题 FAQ

- **中文显示** → 文本节点由浏览器直接排版（KaTeX 仅处理 $…$ 段），中英文均可正常显示。
- **画布放不下** → 拖到边自动扩展（建议先设置 Graph 默认尺寸）；或按 `zz` / 点工具栏 **Fit** 一键缩放到刚好放下。
- **代码没同步** → cd 模式务必用右下/右上的 **Insert（`ok`）** 或代码面板 **Parse** 回写，否则 canvas
  更新不到插件 graph。
- **键没反应** → 看左下状态栏：是不是还在 INSERT/ARROW_EDITING；或者键被重绑过 → 去设置里看。
  实在想不起来就按 `?` 打开速查表（表里显示的就是**当前生效**的键位）。
- **画布上没画坐标轴** → 在属性面板 **Axis** 里勾上 *Show Axis*；三种样式（Box / Middle / Axes）
  与极坐标都会在画布上如实画出来，和生成的 LaTeX 一致。
- **点不中小图形** → 形状**内部**也可以点中（不必精确点边线）；太小时可以用工具栏 **Fit**
  放大后再点。
- **颜色选错了，笔记编译报错** → 自定义颜色会校验：只接受 `red` / `blue!50` 这类 xcolor 名字，
  以及 `#ff8800` 这类十六进制值（后者会自动在导出的代码里声明成 `\definecolor`，
  因为 xcolor 不认写在选项里的裸十六进制）。填错会在选择器里当场提示，不会写进笔记。
- **函数名没了** → 函数名会以 `% tkz-function: 名字` 的注释形式保存在代码里，不会丢。
- **文字节点不见了 / 跑到别的图形上去了** → 旧版解析器会把"排在形状后面的独立文字节点"
  误当成该形状的标签吞掉（文字节点在代码里也叫 `tkz_…`）。现已按"只有菱形/椭圆的
  标签才会单独成行、且必须落在形状正中"来判定，独立的文字节点不会再被吞。
- **cd 模式想用旧 hjkl** → 参考引擎（Preact）固定方向键/数字，不再有 hjkl；方向键同样顺手。
  （旧 hjkl 的 Vim 用法留给了 picture 模式。）
- **渲染偏移** → 画布是**所见即所得**（对象直接按模型坐标绘制在 SVG 上），不存在第二套渲染；
  若要核对生成代码，用 Code 标签比对即可。（旧的工具栏 Position/Calibrate 按钮已移除。）
- **`ok` 后没插入** → 光标不在 ` ```tikz ` 块内时是"新建"语义（会替换整个当前笔记的代码块），
  请把光标放进目标代码块再开编辑器。

## 十七、开发与构建

```bash
npm install                     # 安装依赖
npm run dev                     # watch 模式 → 输出 main.js
npm run build                   # 生产构建（tsc 校验 + esbuild）

npm test                        # 编译 harness 并跑全部 Playwright 测试（269 项）
npm run test:audit              # 审核回归测试（54 项，每条都对应一个修过的缺陷）
npm run test:e2e                # 真实 TikZJax 引擎端到端编译验证（5 个样例）
```

三个测试套件都是无头 Chromium 跑真实 DOM：

- `test/run-test.mjs` —— 功能回归（269 项）。
- `test/run-audit.mjs` —— 2026-11 审核引入的缺陷回归（47 项）。
- `test/run-e2e-tikzjax.mjs` —— 把生成的代码丢进**真实 TikZJax 引擎**编译，
  确认笔记里的代码块真能出图（需要网络拉 TeX 核心）。

> ⚠ 改 `src/**` 或 `src/cd/*` 后**必须**重跑 `node test/build-harness.mjs`
> （`npm run build` 只编 `main.js`，不会更新 `test/harness.js`，否则测的是旧 bundle）。
>
> ⚠ `tsc -noEmit` **不检查 `.svelte` 文件**——组件里的类型/引用错误它一律看不见。
> 新增组件时请人工核对 import，或引入 `svelte-check`。

处理细节（架构、键位注册、坑点）见仓库中的 **Dev.md**。
